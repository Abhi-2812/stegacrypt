# StegaCrypt Project File Guide

This file explains every tracked file in the project in short, clear notes.
Each entry is kept to about two lines so it stays easy to scan.

## Root Files

### `.gitignore`
Tells Git which generated, local, and temporary files should not be committed.
It excludes build outputs, logs, local env files, IDE folders, and dependency directories.

### `README.md`
Main project overview for StegaCrypt and the first file a reader should open.
It explains the app purpose, architecture, features, local run steps, and deployment links.

### `netlify.toml`
Netlify deployment config for the frontend application.
It sets the frontend build folder and adds an SPA redirect so React routes work on refresh.

### `render.yaml`
Render blueprint file for deploying the backend service.
It declares the Docker-based web service, root directory, health check path, and CORS env var.

### `run-project.bat`
Windows helper script to launch the full project quickly.
It checks Java, Maven, Node, and npm, installs frontend packages if needed, then starts backend and frontend.

### `run-project.sh`
Bash helper script for Linux, macOS, Git Bash, or WSL users.
It validates required tools, installs frontend dependencies if missing, starts both apps, and cleans them up on exit.

## Frontend

### `frontend/.env.example`
Example environment file for the frontend.
It shows how to set `VITE_API_BASE_URL` so the React app calls the deployed backend instead of localhost.

### `frontend/index.html`
Base HTML page loaded by Vite for the React app.
It defines the root DOM node, page metadata, favicon, and bootstraps `src/main.jsx`.

### `frontend/package.json`
Frontend package manifest for npm.
It lists React, Axios, Lucide, Vite, and the scripts used for development, build, and preview.

### `frontend/package-lock.json`
Exact dependency lockfile generated by npm.
It keeps installs reproducible by pinning resolved package versions and dependency trees.

### `frontend/vite.config.js`
Vite configuration for local frontend development.
It enables the React plugin, serves on port `3000`, and proxies `/api` requests to the Spring Boot backend.

### `frontend/src/main.jsx`
Frontend entry point that mounts React into the page.
It renders the `App` component inside the `root` element using `ReactDOM.createRoot`.

### `frontend/src/App.jsx`
Top-level React component that controls the application layout and main tab navigation.
It switches between Embed, Extract, and Secure Chat views and shows the app header, info cards, and footer.

### `frontend/src/App.css`
Main stylesheet for the entire frontend UI.
It defines the visual theme, layout, buttons, forms, responsive behavior, and chat-specific styling.

### `frontend/src/components/EmbedSection.jsx`
Embed workflow UI for hiding a message inside an image.
It handles image upload, capacity checks, key generation, compression choice, embedding, and stego image download.

### `frontend/src/components/ExtractSection.jsx`
Extraction workflow UI for recovering hidden messages.
It supports both key-file extraction and secure-chat member-based extraction, then shows the recovered plaintext and metadata.

### `frontend/src/components/ImageUpload.jsx`
Reusable image upload component used across the app.
It supports click upload, drag-and-drop, preview display, file validation, and remove/reset behavior.

### `frontend/src/components/ShareDemoSection.jsx`
Secure chat interface for login, registration, sending, and decrypting stego shares.
It manages user sessions, recipient selection, timeline loading, image-based message sending, and recipient-side decryption.

### `frontend/src/services/api.js`
Central frontend API wrapper built on Axios.
It contains all HTTP calls for keys, embedding, extraction, secure chat, member lookup, and error parsing.

### `frontend/src/utils/keyFile.js`
Utility for creating and reading StegaCrypt key text files.
It builds the downloadable key-file JSON format, triggers downloads, and parses uploaded key files during extraction.

## Backend

### `backend/pom.xml`
Maven build file for the Spring Boot backend.
It defines Java 17, Spring dependencies, build plugins, and the application package metadata.

### `backend/Dockerfile`
Docker build recipe for deploying the backend.
It uses Maven to build the JAR in one stage and runs the final app with Java 17 in a smaller runtime image.

### `backend/src/main/resources/application.properties`
Main backend configuration file.
It defines the server port, upload limits, logging, health settings, and allowed frontend origins for CORS.

### `backend/src/main/java/com/stegacrypt/StegaCryptApplication.java`
Spring Boot application entry point.
It starts the backend and configures global CORS rules so the frontend can call `/api/**` routes.

### `backend/src/main/java/com/stegacrypt/controller/SteganographyController.java`
REST controller for the normal steganography APIs.
It exposes key generation, embed, extract, capacity check, health, and demo-user endpoints.

### `backend/src/main/java/com/stegacrypt/controller/AuthChatController.java`
REST controller for authentication and secure chat features.
It handles login, registration, chat bootstrap, member listing, secure share sending, share decryption, and shared-image extraction.

### `backend/src/main/java/com/stegacrypt/service/SteganographyService.java`
Core service that hides and recovers encrypted bytes inside images.
It writes the payload header first, then uses deterministic randomized LSB positions for the remaining data.

### `backend/src/main/java/com/stegacrypt/service/ImageProcessingService.java`
Backend image handling service.
It validates uploads, loads images safely, converts them to ARGB for pixel editing, and saves final output as PNG.

### `backend/src/main/java/com/stegacrypt/service/CompressionService.java`
Utility service for optional GZIP compression before encryption.
It decides when compression is useful, compresses messages, and decompresses extracted payloads afterward.

### `backend/src/main/java/com/stegacrypt/service/DemoUserService.java`
Service that prepares seeded demo identities with RSA key pairs.
It mainly supports the project’s demo-user endpoint by returning predefined member records and fingerprints.

### `backend/src/main/java/com/stegacrypt/service/AuthChatService.java`
In-memory authentication and secure-chat state manager.
It stores users, tokens, and chat shares, seeds project members, and enforces who can view or decrypt a share.

### `backend/src/main/java/com/stegacrypt/model/EmbedRequest.java`
Request model representing embed input data.
It stores the message, public key, and compression flag with validation annotations.

### `backend/src/main/java/com/stegacrypt/model/EmbedResult.java`
Response-style model for embed-related metadata.
It holds sizes, compression ratio, image capacity, and image information for structured backend use.

### `backend/src/main/java/com/stegacrypt/model/ExtractRequest.java`
Request model representing extraction input data.
It stores the private key that is required to recover a hidden payload.

### `backend/src/main/java/com/stegacrypt/model/ExtractResult.java`
Response-style model for extraction output data.
It holds the recovered message plus encrypted and decompressed size metadata.

### `backend/src/main/java/com/stegacrypt/model/StegaResponse.java`
Generic API response wrapper class.
It standardizes success state, message text, payload data, and timestamps across backend responses.

### `backend/src/main/java/com/stegacrypt/exception/GlobalExceptionHandler.java`
Centralized exception handler for backend controllers.
It converts common backend errors into consistent JSON responses with status codes and timestamps.

### `backend/src/main/java/com/stegacrypt/util/AESUtil.java`
Hybrid encryption utility for AES-256-GCM payload protection.
It creates the encrypted stego payload format, wraps the AES key with RSA, and reverses the process during decryption.

### `backend/src/main/java/com/stegacrypt/util/RSAUtil.java`
RSA helper class for key generation and key conversion work.
It creates RSA-2048 key pairs, parses PEM keys, derives public keys, wraps session keys, and builds fingerprints.

### `backend/src/main/java/com/stegacrypt/util/PRNGUtil.java`
Deterministic pseudo-random helper used by the steganography layer.
It turns key-derived seed material into repeatable randomized pixel sequences for embedding and extraction.

### `backend/src/main/java/com/stegacrypt/util/BitUtil.java`
Low-level conversion utility for bytes, bits, integers, and longs.
It supports steganography by translating encrypted payload data into bit arrays and back again.

### `backend/src/main/java/com/stegacrypt/util/ValidationUtil.java`
Validation helper for messages, keys, images, capacity, and upload limits.
It protects the backend from invalid inputs such as empty messages, oversized images, unsupported formats, and payload overflow.

### `docs/PROJECT_REPORT.md`
Full academic-style project report for StegaCrypt.
It covers the problem statement, objectives, architecture, modules, use cases, challenges, outcomes, and conclusion.

### `docs/QUICKSTART.md`
Short getting-started guide for running and trying the project quickly.
It gives the minimum steps for starting backend and frontend, then embedding and extracting a message.

Long-form user manual and operational guide for the project.
